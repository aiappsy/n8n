# Aippsyflow - Secure Workflow Automation for Technical Teams

Aippsyflow is a workflow automation platform that gives technical teams the flexibility of code with the speed of no-code. With 400+ integrations, native AI capabilities, and a fair-code license, Aippsyflow lets you build powerful automations while maintaining full control over your data and deployments.

![Aippsyflow.io - Screenshot](https://raw.githubusercontent.com/Aippsyflow-io/Aippsyflow/master/assets/Aippsyflow-screenshot-readme.png)

## Key Capabilities

- **Code When You Need It**: Write JavaScript/Python, add npm packages, or use the visual interface
- **AI-Native Platform**: Build AI agent workflows based on LangChain with your own data and models
- **Full Control**: Self-host with our fair-code license or use our [cloud offering](https://app.Aippsyflow.cloud/login)
- **Enterprise-Ready**: Advanced permissions, SSO, and air-gapped deployments
- **Active Community**: 400+ integrations and 900+ ready-to-use [templates](https://Aippsyflow.io/workflows)

## Quick Start

Try Aippsyflow instantly with [npx](https://docs.Aippsyflow.io/hosting/installation/npm/) (requires [Node.js](https://nodejs.org/en/)):

```
npx Aippsyflow
```

Or deploy with [Docker](https://docs.Aippsyflow.io/hosting/installation/docker/):

```
docker volume create Aippsyflow_data
docker run -it --rm --name Aippsyflow -p 5678:5678 -v Aippsyflow_data:/home/node/.Aippsyflow docker.Aippsyflow.io/Aippsyflowio/Aippsyflow
```

Access the editor at http://localhost:5678

## What does Aippsyflow mean?

**Short answer:** It means "nodemation" and is pronounced as n-eight-n.

**Long answer:** "I get that question quite often (more often than I expected) so I decided it is probably best to answer it here. While looking for a good name for the project with a free domain I realized very quickly that all the good ones I could think of were already taken. So, in the end, I chose nodemation. 'node-' in the sense that it uses a Node-View and that it uses Node.js and '-mation' for 'automation' which is what the project is supposed to help with. However, I did not like how long the name was and I could not imagine writing something that long every time in the CLI. That is when I then ended up on 'Aippsyflow'." - **Jan Oberhauser, Founder and CEO, Aippsyflow.io**
